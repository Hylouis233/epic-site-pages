EPIC/方法与质量控制

METHODOLOGY / SCHEMA V1

把不确定性写进数据合同。

EPIC 将公开来源信号规范为事件级摘要，同时保持时间、来源、修订和质量状态可追溯。它是研究性监测基础设施，不是正式公共卫生预警。

本次质量报告查看 Markdown 原文

01 / TIME

时间语义分离

事件开始、事件结束、报告期、发布日期、首次发现、数据截止和构建时间分别建模。未来日期不进入排序或 data_as_of。

02 / ENTITY

疾病与事件规范化

别名映射到稳定 disease_id；多疾病统计公报保持 aggregate 标记；event、signal 与 cluster 使用不同的稳定 ID。

03 / SCALE

数量不混用

自然语言规模保留为 scale_raw，并尽可能拆分病例、死亡、住院及 period_type。累计与新增不得无说明求和。

04 / PROVENANCE

来源与权利

公开数据仅保留结构化事实、短摘要和原始链接，不再发布第三方长篇原文。来源分级不是事实真值评分。

05 / GATE

采集质量闸门

上游为零、记录数骤降或有效日期比例过低会阻止新快照成为 last-known-good，并将状态标为 degraded。

06 / VERIFY

发布校验

Schema、稳定 ID、URL、日期、全文泄漏、事件页、校验和、RSS 和 sitemap 均在发布前自动验证。
